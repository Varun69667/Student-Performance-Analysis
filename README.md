# Student Performance Data Analysis

## About the Project
A beginner-friendly Data Science project developed using Python to analyse student academic performance and attendance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Features
- Student marks analysis
- Average marks calculation
- Automatic student grading
- Top and lowest performer identification
- Attendance analysis
- Correlation calculation
- Data visualisation
- Grade distribution chart

## Dataset
The project uses a sample dataset containing student names, subject marks and attendance percentages.

## Project Objective
To understand how Python and data analysis libraries can be used to extract meaningful insights from student performance data.
